# Análise de Eficiência Solar

Script em Python desenvolvido para o processamento, limpeza e análise de dados operacionais de geração fotovoltaica.

## 🚀 Tecnologias Utilizadas
* **Python 3**
* **Pandas** (Tratamento e manipulação de dados)

## 📌 Funcionalidades
* Leitura e validação de arquivos de dados (CSV).
* Tratamento de erros e exceções na carga de arquivos.
* Cálculo da taxa de eficiência energética com base na capacidade nominal.
